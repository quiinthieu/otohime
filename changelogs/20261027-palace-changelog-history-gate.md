# Ship current build history with a strict production gate

`scripts/history-index.ts` now computes `total` as all reachable commits at the indexed revision (unfiltered `git rev-list --count`), while `entries` remains bounded to the newest `<=200` non-merge commits. It adds `--strict` (and `--rev=<sha>` / `GITHUB_SHA` binding) for both generation and `--check`: shallow clones, missing git, mismatched build SHAs, stale leaves (`> MAX_LAG = 20`), unindexed non-merge commits, or `total` mismatches fail nonzero before any production bundle can be uploaded. Outside `--strict`, permissive developer and archive fallback behavior is preserved.

`.github/workflows/ci.yml` checks out complete git ancestry (`fetch-depth: 0`) in `checks`, `preview`, and `production`, regenerates and validates `content/history.json` strictly before and after every build, and runs the read-only live probe (`scripts/probe-history.sh`) after `verify-deploy.sh` in `production` (plus `--self-test` in `checks`). `scripts/verify-history-build.sh` verifies a real local production build and headless Chrome inspection of `/ryugu` against local git metadata while restoring the committed fallback on exit.

Also hardened `e2e/console-errors.ts` for HTTP/2 empty reason phrases (`404 ()`) on `/api/ghosts`, ensured `e2e/riso-headings.test.ts` waits for `.riso-text[data-riso-state]` hydration before testing the Pocket `A Open` ViewTransition, caught skipped ViewTransition `AbortError`s on rapid double-click in `components/theme-toggle.tsx`, and eliminated the detached-iframe attribution race on `/music` in `scripts/probe-end.mjs`.
