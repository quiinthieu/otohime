# Repository instructions

Read and follow the tracked `AGENTS.md` in this repository, including its Next.js documentation requirement and Git identity guidance. Read any more specific instructions in the directories you change.

For the site owner's own work, check the effective author with `bash scripts/setup-owner-git.sh --check` before committing. A new owner-controlled clone can be prepared with `bash scripts/setup-owner-git.sh --configure`; the setting is local to that clone and shared by its linked worktrees. Do not use an agent no-reply address for commits made on the owner's behalf or reattribute another person's work.
