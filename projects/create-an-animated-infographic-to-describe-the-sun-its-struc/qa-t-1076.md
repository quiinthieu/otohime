## The failure

`app/(sun)/sun.css:27-35` declares `.visually-hidden` with `position: absolute;
width: 1px; height: 1px; clip-path: inset(50%); white-space: nowrap` but without
`overflow: hidden`. The page's `<h1 class="visually-hidden">The Sun, in eight
chapters</h1>` (`app/(sun)/sun/page.tsx:28`) is a 32 px nowrap line. clip-path
hides it but it still counts as scrollable overflow, so at 390 px the document is
403 px wide and the page shifts sideways on a phone.

Bisect at 390×844, measuring `document.documentElement.scrollWidth`:

| Injected style | scrollWidth |
| --- | --- |
| none | 403 |
| `.sun-svg{overflow:hidden}` / no filter / hide scenes / hide corona / hide `.stage` / hide `.chapters` | 403 |
| hide `h1.visually-hidden` | 390 |
| `.visually-hidden{overflow:hidden}` | 390 |

The build contract requires a "390px layout without overflow", and the plan's QA
step 3 checks "no horizontal overflow at 390 px". See `fix-plan-t-1076.md`.
