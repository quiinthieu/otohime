PaperLayer is the route owner. Its one gesture port arbitrates peel, hold/fetch and the ball grip. A ball grip reparents before acquiring pointer capture; it never competes with the source card's fetch listeners. Source DOM, accessible names, links and layout boxes remain in place. Only original child paint is concealed; Read, original-content focus and Reset restore it synchronously.

The crumple adapter reserves at most eight slots, including pending imports. Each slot owns its fold renderer, snapshot grip and flight adapter. Generation tokens invalidate pending imports after recovery. The fold bitmap and snapshot preparation use DPR at most two; the temporary snapshot Canvas is released immediately. The flight adapter owns exactly one rAF and one captured pointer. It releases both on disposal, removes its proxy, and restores focus to the source Crumple control when the removed grip owned focus. Reset controls and focused source links retain their own focus.

Physics uses viewport CSS pixels, px/s velocities clamped to ±1200, gravity 980px/s², 120Hz fixed substeps, air/ground friction and restitution bounded below one. Finite deltas clamp to 250ms; invalid/negative deltas do no work. Radius-18 circles collide with two horizontal basket rim segments. Only a downward crossing inside the opening is a hit. Hits remain observable as `data-ball-state=basket`; misses settle as `rest`. Neither creates a score nor removes content. The injected active clock has a hard 5000ms bound; remaining energy is zeroed and the current location is clamped safely into the viewport. No rAF remains after rest, hit or recovery. Hidden pages cancel flight instead of accruing hidden elapsed time.

The server reserves a 156px footer slot around a 148×100 ink SVG. The measured SVG bounds map explicitly to the opening and bottom. Source rectangles and pointer samples are viewport coordinates. Flight uses fixed positioning; basket settlement converts to document coordinates by adding scrollX/Y, so a landed ball follows the basket on scroll. Keyboard Toss aims at a visible opening. With the basket offscreen, or with reduced motion, it places the ball directly at the measured basket in document coordinates, without scrolling. Pointer flicks simulate against the currently visible opening. Read and Reset stay at the source card. Footer navigation, waterline and shell remain separate controls.

Per-card Reset/Read clears that card's fold, flight, tear session flag and matching fetch, preserving other cards. The route-local global reset port and Iron flat cancel all fetch/fold/flight owners, clear every registered card and restore paint. Iron flat adds one 420ms CSS sweep after restoration; reduced motion skips it. A new reset removes any previous sweep. Paper session storage uses only `paper:v1:<route>`; no recovery path writes Kame's `kame:v1` localStorage name, streak or dismissal.

Escape, modal opening and live motion changes perform full recovery. Blur, resize, hiding and source removal cancel active adapters and restore paint. Route departure clears paper session state. Pagehide tears down adapters, captures, listeners and pending imports; pageshow remounts through hydration readiness and tears down any prior mount first. Renderer import, context or paint failure restores the source and leaves Read/Reset usable. React teardown releases the same route owner. No global custom event API or dependency is introduced.
