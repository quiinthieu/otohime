## Notes (non-blocking)

- With JavaScript on, the whole svg box is `touch-action: none`. So a finger
  on the frame corners, which are inside the svg but off the disc, no longer
  scrolls the page. The plan's cycle-2 decision accepts this ("more code for
  a few pixels"). The explainer and the controls still scroll by finger.
- In Tokyo, the point 0.3 × face-width above the centre falls on the frame,
  not the disc, because the window is clipped. The probe's hit-test fallback
  (recorded by the software engineer) is what makes its start point valid.
