## The defect

`app/(planisphere)/_components/wheel.tsx:110-112` builds the three circles
with `inkCircle(CX, CY, …)`, which bakes the wheel's centre (360,380) into the
path data. The paths are then drawn inside groups that are already
`translate(${CX} ${CY})`: line 160 for `rimOuter` at line 184, and line 241
for `ringOuter` and `ringInner` at lines 244-245. The centre is therefore
added twice, which puts all three circles at (720,760).

The walk cannot see this, because it counts attributes. The probe's first
overflow check caught it as `g.ink` paths reaching past the viewport. The
SVG clips them, so the page does not scroll.

A scratch build with `inkCircle(0, 0, …)` on those three lines (reverted,
not committed) draws both hour-ring circles and the rim circle around the
wheel. No ink path reaches past the SVG for Tokyo in December or Sydney.
