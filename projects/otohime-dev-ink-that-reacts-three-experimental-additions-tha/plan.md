# Ink That Reacts: three experimental additions in the pocket-console style (pm-243)

**Idea.** otohime.dev: Ink that reacts. Three experimental additions that stay in the paper-and-ink pocket-console style: (1) an ink-particle hero on `/`, (2) rubber-stamp physics headings on `/play`, (3) "Ask the console", a site-only Q&A that prints on a paper receipt.

Research: [research.md](research.md) (rep-4813, run-8332). Planned at `dd1e8e1` (main). Read the Next 16 docs in `node_modules/next/dist/docs/` before writing code (`AGENTS.md`); relevant pages: `01-app/02-guides/lazy-loading.md`, `01-app/01-getting-started/15-route-handlers.md`.

## Decisions

| Decision | Why |
| --- | --- |
| No motion library, no three in `(site)`. Particles and stamps are a hand-written WebGL2/Canvas2D draw and a ~200 line box solver. | README §Motion bans a motion library; a raw points program is a few KB. |
| Engines live in `lib/` (pure, `node --test`); islands load via `next/dynamic(..., {ssr:false})` from a client wrapper. | Matches Elements and `lib/motion.test.ts`; each feature ships its own chunk. |
| Particle engine is `lib/ink-particles.ts`, not `lib/ink.ts`. | `app/(articles)/_lib/ink.ts` already exists (Gazette rough.js ink). |
| Each engine ships inside the island task that uses it (ink hero, stamp board). | The plan validator accepts only `scripts/`, `projects/`, `docs/`, `pkg/`, `servers/`, `tools/`, `sre/`, `.gitlab/`, `gameplay/` or a top-level file in `interfaces`; `lib/`, `app/` and `components/` are refused (`missing_interfaces`). Each task still names its real files in action_items. |
| Ask index is generated by `scripts/ask-index.ts` into `public/ask-index.json`. | `app/(articles)/_lib/isolation.test.ts` forbids `components/`, `content/`, `lib/` from importing the Gazette; `scripts/` is outside it. |
| Ask is offline-first. The LLM tier is optional, behind `ASK_LLM=1` + `ANTHROPIC_API_KEY`, and ships with a fake-client test. | No secret is needed to ship and preview; the key is an operator chore raised only by task 5. |
| Ask opens from a visible chip. Select is wired only if handheld exposes it at rebase time. | pm-242 owns `components/handheld.tsx` and the B button; this plan cannot wait for it. |
| Stamps are scoped to `/play` (h1 "Play" and h2 "In rotation"); no any-heading long-press. | The long-press fights selection and the iOS callout and collides with view-transition names. |
| Ink hero simulates at 60 Hz and draws at 24 fps (`INK_FPS`). | 12 fps lags the pointer; the owner can tune the constant. |
| `qa:"skip"` only on task 3 (index and offline answerer, nothing a person sees yet); `required` on every visible or migration task. | `skip` is only allowed where nothing a person sees changes and verification fully proves the task. |
| The LLM route's ready probe is `GET /api/ask`: 404 while disabled, 200 with `{"enabled":true}` when on. | `ready_probe` is GET-only; a POST probe is not expressible. |

## Acceptance

- Ink hero: on `/` at 1366x768 and 390x844 the canvas reaches `data-state="settled"` after idle, scatters within 3 s of a synthetic pointer move, and under reduced motion no canvas renders. The `ink-hero` chunk is never requested on `/work`. CLS 0.
- Stamps: on `/play`, "Stamp it" produces one block per letter, the real "Play" heading still resolves by role, a synthetic drag leaves at least one mark, Tidy restores the heading and removes the overlay. Reduced motion stays static.
- Ask: chip opens the dialog; "what is shore" links to `/shore`; "pizza recipe" prints NO MATCH; Escape returns focus. Neither the chunk nor `ask-index.json` loads before first open.
- LLM tier: with `ASK_LLM` unset the route returns 404; with the fake client it returns 200 with mapped links; the 11th request in an hour returns 429. Once the operator chore is done, the live `GET /api/ask` returns 200 (a watch, not a gate of this plan).

## Risks

- DPR 3 phones and integrated GPUs: DPR capped at 2 and N tiers.
- Stamp overlay must not add `touch-action: none` to the page; only blocks take it.
- pm-242 collisions in `components/handheld.tsx`, `globals.css`, `lib/sound.ts`: add, never rewrite; rebase on a rejected push.
- Each stylesheet's reduced-motion block stays last; `lib/motion.test.ts` stays green.
