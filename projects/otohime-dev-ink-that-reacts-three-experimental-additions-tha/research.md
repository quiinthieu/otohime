# Research: Ink that reacts (pm-243, run-8332, rep-4813)

**Idea.** Three experimental additions in the paper-and-ink pocket-console style: (1) an ink-particle hero that scatters from the pointer and bleeds back, (2) rubber-stamp physics headings on /play with a Tidy button, (3) "Ask the console", a site-only Q&A that prints on a paper receipt. Lazy per feature, mobile friendly, accessible.

**Short answer.** Checked against otohime at 9550093 (`npm ci` + `npm test` = 1,449 pass). All three can be built with no new runtime dependency and no secret, as seven tasks. Four house rules decide the design: README §Motion says no motion library (so no matter.js: a ~150-200 line box solver instead), figures run on twos from pure reducers, the resting pose is the base style (server-rendered SVG/HTML; JS only adds motion), and `app/(articles)/_lib/isolation.test.ts` forbids `components/`, `content/`, `lib/` and other groups from importing the Gazette, so the ask index is generated by a script into `public/`. The three X references are login-walled (oEmbed HTTP 402); the idea text is the brief.

## 2. Feature 1: ink-particle hero (home)

- **Shape source.** A committed SVG wordmark, fixed viewBox. At mount, stroke it into an offscreen canvas (`Path2D`), sample opaque pixels on a seeded jittered grid → N targets: 2,400 on desktop, 1,200 when `hardwareConcurrency <= 4` or width < 640, 600 on Canvas2D.
- **Physics (pure).** Struct-of-arrays `Float32Array`. Spring to target, damping, a pointer impulse inside R ≈ 70 px with falloff scaled by pointer speed (a still cursor does not keep blowing), plus a curl-noise drift while displaced so the return bleeds rather than snaps. `settled()` when velocities and offsets are under 0.3 px for 6 steps → loop stops.
- **Frame rate.** Simulate at fixed 60 Hz, draw at 24 fps (two-frame hold); one constant `INK_FPS` so the owner can try 12.
- **WebGL2.** One `gl.POINTS` draw, soft round speck, paper grain as hash noise in alpha. Ink colour from the CSS variable, re-read on theme change.
- **Fallback ladder.** Reduced motion, `saveData`, or no motion-capable context → no canvas; the SVG mark is the resting pose. WebGL2 missing → Canvas2D. `webglcontextlost` → canvas removed, SVG shows.
- **Mount.** `h1` stays real text; the mark is `aria-hidden`. Client wrapper loads `next/dynamic(..., {ssr:false})` on idle, in view, media checks pass. Fixed aspect-ratio box (CLS 0). Pause when hidden or out of view.

## 3. Feature 2: rubber-stamp physics type (/play)

- **Scope.** /play only: the h1 "Play" and h2 "In rotation". The any-heading long-press is cut: it fights selection and the iOS callout, and collides with `view-transition-name`. The component takes any string so it can widen later.
- **Entry.** A "Stamp it" chip beside the heading plus a 500 ms long-press on /play only.
- **Solver (pure).** 6-14 oriented boxes, SAT box-box, sequential impulses, restitution 0.15, friction 0.6, sleep after 30 slow steps, velocity clamp, fixed 120 Hz substeps. Drag = stiff spring; release velocity = toss.
- **Ink marks.** Hard landings push `{x, y, angle, glyph, alpha}` onto a capped list (last 40), drawn faintly under the blocks.
- **Tidy.** Bodies spring critically damped to home pose, then the real heading returns and the overlay unmounts.
- **Reduced motion.** Letters placed with a slight scatter, no falling; Tidy snaps.
- **Keyboard.** Each block is a button when stamped; arrows nudge; Space picks up/drops; Escape or Tidy restores.

## 4. Feature 3: Ask the console

**Index.** `scripts/ask-index.ts` (`npm run ask:index`; `npm run ask:check` in CI) imports `content/site.ts` and `ARTICLES` and writes `public/ask-index.json`: passages ≤ 60 words, tokens lowercased, ASCII-folded, stoplisted, lightly stemmed. Est. 25-40 KB raw.

**Offline answerer (default, no key).** `lib/ask.ts`, pure: BM25 + typo tolerance (edit distance ≤ 1 for terms ≥ 5 chars) + a few intent rules. Reply: 1-3 terse lines in the terminal voice, each a substring of the index or a fixed template. Below a score floor: `NO MATCH. TRY: projects, notes, stack.`

**UI.** The console's Select button (if exposed) and a visible "Ask" chip open a native `<dialog>` (focus trapped, Escape closes, focus returns). Answer prints as a paper receipt; the full text is in the DOM inside `aria-live="polite"`, the typewriter is a visual mask only; reduced motion shows it instantly. Links are real `<Link>`s.

**LLM tier (optional).** `app/api/ask/route.ts`, off unless `ASK_LLM=1` and `ANTHROPIC_API_KEY` are set (404 otherwise). Retrieval stays local; the model cites passage ids and the route maps them to hrefs. `@anthropic-ai/sdk`, model from `ASK_MODEL`, default `claude-opus-5-5`. Budget and rate limit in Postgres (`ask_usage` table, per-IP-hour and per-day buckets). Any SDK error or limit → offline answer marked `(OFFLINE)`.

**Operator chore (task 7 only).** Add `ANTHROPIC_API_KEY` and `ASK_LLM=1` to Vercel Production env. The task ships without it (route 404s, offline works) and is proved with a fake client.
