## Code read

- `crank.ts`: the step is `((d % 360) + 540) % 360 − 180` (the short way round). The total has a floor of 0, latching to 90 once reached, so `fire` is true exactly once per drag. The tests cover each action-item case: a quarter turn, counter-clockwise, 350→20 = +30, jitter plus a 400-step seeded storm, and the compass points.
- `machine.tsx`: `onCrank` is the app's `crank()`, the same function as the Turn button. That function still guards `phase !== "loaded"`. The non-passive `touchstart` listener only calls `preventDefault` while `data-grab` is set, so outside `loaded` a finger on the dial still scrolls the page.
- The non-goals were respected: no haptics, sound or inertia. The Turn button stays, and `turnFrames` is unchanged (the same-seed rounds both took 1496 ms).
