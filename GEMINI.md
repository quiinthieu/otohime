# Repository instructions

Read and follow the tracked `AGENTS.md` in this repository, including its Next.js documentation requirement and Git identity guidance. Read any more specific instructions in directories you change.

For the site owner's own work, check the effective author with `bash scripts/setup-owner-git.sh --check` before committing. A new owner-controlled clone can use `bash scripts/setup-owner-git.sh --configure`; this changes only the clone's Git configuration, shared by its linked worktrees. Do not use an agent no-reply address for commits made on the owner's behalf or reattribute another person's work.
